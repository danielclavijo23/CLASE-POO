**Domotic Circuit Simulator **

This folder contains the implementation for Final Course Project of the Object-Oriented Programming course.  

**Project Structure (Layered Architecture)**
- README.md – (this file)
- Final Course Project.pdf – Main document containing all required sections.
- DomoticCircuitSimulator/
  - logic/: domain classes
  - data/: persistence
  - ui/: advanced UI
  - icons/: png icons
  - uml.png: UML diagram image
  - Video1: Video

**Running the Project**
- Requirements
  - Python 3.10+
  - PyQt5
- Install dependencies
  - pip install pyqt5
- Run the simulator
  - python main.py

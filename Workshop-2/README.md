**Description**

This document presents the second phase of the domotic circuit simulator project. It briefly defines the updated conceptual model, includes the system’s UML class diagram, and outlines how object-oriented principles (encapsulation, inheritance, and polymorphism) guide the design.

Basic Python code snippets illustrate the initial structure of the simulator, and the architecture is organized into three layers: presentation, logic, and data. The document also explains how components such as sensors, controllers, and actuators interact within the simulator.
